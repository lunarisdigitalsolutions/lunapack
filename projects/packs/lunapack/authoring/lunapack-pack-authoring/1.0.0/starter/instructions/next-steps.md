# Finish the pack

The starter pack is under `examples/starter-pack/`. Move it to
`<pack-id>/1.0.0/`, then replace the example identity, author, description,
targets, fragment markers, script, and content. Run `luna pack validate` from
that version directory.

Review `docs/packs/writing-a-good-pack.md` before publishing. Test installation,
repeated installation, updates, local edits, conflicts, and uninstall behavior.
