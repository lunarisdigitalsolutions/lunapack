# MVP

## Outcome

The MVP is complete. Teams can now author first packs and evaluate the end-to-end
workflow in consumer projects.

## Delivered Scope

- Version-1 project, lock, and pack schemas.
- Local, Git, and GitHub-shorthand pack sources.
- Discovery and search across schema-valid packs.
- Exact dependency resolution and parameterized templates.
- Install, dry-run, outdated, update, uninstall, and audit lifecycle commands.
- Transactional state changes and digest-based managed-file protection.
- Ordered install and update hooks for trusted scripts and guided instructions,
  with independent skip controls, consumer-owned script trust, and persistent
  blanket script denial.
- Workspace-aware root summaries and contextual next-step commands for the core
  setup, catalog, and lifecycle journey.
- CLI-first, incremental pack-manifest creation and maintenance with valid
  intermediate states and minimal schema-required initialization output.

## Evaluation Goal

Validate that a small, useful pack can be authored, sourced, installed, updated,
audited, and safely removed without losing consumer-owned changes.
