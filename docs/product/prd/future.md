# Product Roadmap

This page records product direction beyond the completed MVP. These capabilities
are not current CLI behavior.

## Trust, Governance, And Security

Add organization policy, accountable ownership, exceptions, signatures,
provenance attestations, publisher identity, security-pack controls, and
vulnerability response.

## Lifecycle Depth

Add automated validation, compatibility policy, managed-content comparison,
synchronization, migration orchestration, and richer rollback guidance.

## Pack-Defined External Sources

Add pack-declared Git source aliases for managed content, resolved through the
same normalized source-fingerprint identity as workspace sources. Add
graph-wide, all-or-nothing consent before install or update adds a new source,
and pack-authoring commands for declaring, reviewing, and removing a pack's
sources.

## Distribution

Add registry providers, hosted catalog metadata, marketplace publishing, and
enterprise administration after trust and lifecycle evidence are mature.

## AI Integration

Add policy-aware agents that can search, explain, recommend, prepare, and
validate pack changes under human governance. Agents will not establish source
trust or approve restricted changes.
