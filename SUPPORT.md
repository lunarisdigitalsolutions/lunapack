# Support

## Usage help

Read the [developer documentation](docs/developer/index.md) first. For a
reproducible defect or documentation gap, open a GitHub issue using synthetic,
non-sensitive data.

Include:

- Luna version and installation method
- Operating system and architecture
- Command and options used
- Minimal pack and project configuration needed to reproduce the problem
- Expected and actual behavior
- Redacted diagnostic output

This community project provides support on a best-effort basis and does not
promise response or resolution times.

## Security and conduct

Report vulnerabilities through [Security](SECURITY.md), not a public issue.
Report community conduct concerns using the private contact in the
[Code of Conduct](CODE_OF_CONDUCT.md).
